# ADR-001 — Plataforma Android

## Decisão

O projeto será desenvolvido como aplicativo Android nativo.

## Motivo

O produto final desejado é um APK e todo o fluxo de desenvolvimento será realizado a partir de dispositivos Android.

## Consequência

A estrutura deve evitar dependências desnecessárias de PC e favorecer ferramentas que consigam trabalhar com o repositório remotamente.
