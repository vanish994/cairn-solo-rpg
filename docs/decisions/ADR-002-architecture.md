# ADR-002 — Autoridade das Regras

## Decisão

O Rules Engine é a autoridade mecânica do jogo.

## Motivo

Modelos de linguagem podem interpretar ou narrar resultados, mas não devem controlar diretamente HP, inventário, rolagens ou outras regras.

## Consequência

Toda alteração mecânica deve passar por uma operação validada do domínio.
