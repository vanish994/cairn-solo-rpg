# Gate 0 — Arquitetura Android e Repositório

## Objetivo

Criar uma base Android simples, compilável e preparada para desenvolvimento por múltiplos agentes.

## Escopo

### Deve existir

- projeto Android;
- Kotlin;
- Jetpack Compose;
- Material 3;
- Gradle;
- package/base namespace definido;
- README;
- STATUS;
- ROADMAP;
- estrutura de documentação;
- `.gitignore`;
- build debug.

### Não deve existir ainda

- regras completas de Cairn;
- combate completo;
- integração real com Gemini;
- prompts finais do GM;
- sistema completo de quests;
- otimizações prematuras.

## Critérios de aceitação

- [ ] Projeto abre no ambiente escolhido.
- [ ] Gradle sincroniza.
- [ ] Build debug passa.
- [ ] APK debug é gerado.
- [ ] APK instala em dispositivo Android.
- [ ] Aplicativo inicia sem crash.
- [ ] Tela inicial aparece.
- [ ] README explica como continuar o projeto.
- [ ] Nenhum segredo está versionado.

## Saída do Gate

Um aplicativo Android mínimo e um repositório capaz de ser entregue a outro agente sem depender de explicações externas.
