# Gate 6 — Combate

## Objetivo

Adicionar combate determinístico e integrado ao GameState.

## Requisitos

- participantes;
- ordem de atuação;
- ações;
- testes/ataques;
- dano;
- HP;
- condições;
- encerramento.

## Critérios de aceitação

- [ ] Combate funciona sem IA.
- [ ] Estado é atualizado corretamente.
- [ ] Narrativa apenas descreve os resultados.
