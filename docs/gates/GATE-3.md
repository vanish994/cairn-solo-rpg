# Gate 3 — Campanha e GameState

## Objetivo

Transformar o personagem em uma campanha persistente em memória.

## Estado mínimo

```text
CampaignState
Character
Inventory
WorldState
SceneState
CombatState
EventHistory
```

## Critérios de aceitação

- [ ] Nova campanha.
- [ ] Localização atual.
- [ ] Cena atual.
- [ ] Eventos registrados.
- [ ] Mudanças de estado verificáveis.
- [ ] Estado não depende da narrativa produzida pela IA.
