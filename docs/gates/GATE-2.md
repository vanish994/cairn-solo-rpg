# Gate 2 — Criação de Personagem

## Objetivo

Permitir criar um personagem válido.

## Fluxo

```text
Novo jogo
→ Nome
→ Atributos
→ HP
→ Equipamento
→ Inventário
→ Confirmação
→ Personagem criado
```

## Critérios de aceitação

- [ ] Validação de entrada.
- [ ] Personagem válido.
- [ ] Estado inicial correto.
- [ ] Equipamentos registrados.
- [ ] Sem dependência do Gemini.
