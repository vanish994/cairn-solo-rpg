# Gate 5 — GM Narrativo

## Objetivo

Usar o Gemini para interpretar intenção e narrar consequências.

## Fluxo

```text
Entrada do jogador
→ Interpretação
→ Engine
→ Resultado mecânico
→ Context Builder
→ Gemini
→ Narrativa
```

## Critérios de aceitação

- [ ] Ações em linguagem natural.
- [ ] Intenção estruturada.
- [ ] Engine valida a ação.
- [ ] Gemini recebe resultado.
- [ ] Gemini narra sem inventar mudanças mecânicas.
