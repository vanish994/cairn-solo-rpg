# Gate 7 — Save/Load

## Objetivo

Persistir campanhas com segurança.

## Requisitos

- serialização;
- armazenamento local;
- identificação de versão;
- migração futura;
- recuperação de erro.

## Critérios de aceitação

- [ ] Campanha salva.
- [ ] Campanha carregada.
- [ ] Estado preservado.
- [ ] Fechar/reabrir não perde save válido.
